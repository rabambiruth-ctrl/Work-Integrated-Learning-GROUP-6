# Work-Integrated-Learning-GROUP-6
 Jane Furse Memorial Hospital – IT Infrastructure Upgrade

Project Overview

This repository contains the documentation and supporting materials for the Work-Integrated Learning (WIL) project focused on the proposed IT infrastructure upgrade at Jane Furse Memorial Hospital in Limpopo, South Africa.

The project aims to improve the hospital's IT infrastructure by addressing network connectivity, cybersecurity, communication, storage and the availability of technology services.

 Project Objectives

- Improve network connectivity across the hospital.
- Establish reliable and secure network infrastructure.
- Introduce network redundancy to improve availability.
- Support communication and information sharing.
- Provide an infrastructure that can accommodate future growth.


Technologies and Infrastructure

The proposed infrastructure includes fibre-optic connectivity, network switches, firewall protection, wireless access points, structured cabling and Microsoft 365 cloud services.
